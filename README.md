### 📦 User Service
## 📄 Описание
User Service — микросервис, отвечающий за управление профилями пользователей. Он включает в себя:
- Регистрацию и обновление профиля пользователя.
- Получение данных пользователя по id и username.
- Хранение базовой информации: имя, email, аватар, описание.
- Этот сервис является источником данных о пользователях для остальных микросервисов.

## ⚙️ Технологии
## Основные технологии
- Java 17: современный язык программирования для создания надежных приложений.
- Spring Boot 3.x: фреймворк для упрощения разработки приложений на Java.
## Базы данных
- PostgreSQL: реляционная база данных для хранения профилей.
- Redis: кэширование часто запрашиваемых профилей.
- Liquibase: инструмент для управления версиями базы данных.
## Взаимодействие между микросервисами
- Kafka: публикация событий создания/обновления пользователя.
- OpenFeign: клиент для взаимодействия с другими сервисами.
## Тестирование
- JUnit 5, Mockito, Testcontainers.
## Дополнительные инструменты
Lombok, MapStruct, Springdoc OpenAPI, Docker, Slf4j.

## 🔗 Связанные сервисы
- Post Service: для связи постов с пользователями.
- Project Service: для связи проектов с владельцами.
- Achievement Service: для начисления достижений пользователям.
- Notification Service: для отправки уведомлений пользователям.
